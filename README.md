# BattleArena 🎮

Gra 2D z widokiem z góry dla dwóch graczy. Projekt zaliczeniowy z programowania obiektowego w C++.

## Technologie
- C++17
- SFML 2.6.1

## Jak uruchomić
1. Sklonuj repozytorium
2. Zbuduj SFML ze źródeł (GCC 13.3.0)
3. Skompiluj projekt: `g++ -std=c++17 src/main.cpp ...`
