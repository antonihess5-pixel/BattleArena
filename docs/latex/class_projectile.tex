\doxysubsection{Detailed Description}
Reprezentuje lecący pocisk lub strzałę 

Klasa obsługuje dwa typy pocisków\+:
\begin{DoxyItemize}
\item Pocisk maga\+: fioletowe kółko, prędkość 400px/s
\item Strzała łucznika\+: zielona kreska, prędkość 280px/s
\end{DoxyItemize}

Pocisk porusza się w jednym kierunku aż trafi w gracza, ścianę lub wyleci poza granice ekranu.
