\doxysubsection{Detailed Description}
Główna klasa gry zarządzająca całą logiką i renderowaniem. 

Klasa \doxylink{class_game}{Game} implementuje wzorzec "{}\+Game Loop"{} i zarządza\+:
\begin{DoxyItemize}
\item Oknem aplikacji SFML
\item Przejściami między stanami gry (Game\+State)
\item Wektorem graczy (polimorfizm przez Player\+Base\texorpdfstring{$\ast$}{*})
\item Wektorem ścian na planszy
\item Fazą układania ścian (\doxylink{class_wall_placer}{Wall\+Placer})
\item Wykrywaniem kolizji między graczami (check\+Combat)
\item Renderowaniem wszystkich ekranów gry
\end{DoxyItemize}

Cykl życia stanu\+: Menu → Character\+Select → Wall\+Placement → Playing → Game\+Over → Character\+Select
