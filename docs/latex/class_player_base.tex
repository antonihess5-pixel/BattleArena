\doxysubsection{Detailed Description}
Abstrakcyjna klasa bazowa dla wszystkich postaci gracza. 

Zawiera wspólną logikę dla klas \doxylink{class_warrior}{Warrior}, \doxylink{class_mage}{Mage} i \doxylink{class_archer}{Archer}\+:
\begin{DoxyItemize}
\item Ruch po ekranie z uwzględnieniem delta\+Time
\item Ograniczenie ruchu do granic okna (clamp)
\item System punktów życia (HP) z paskiem zdrowia
\item Abstrakcyjna metoda \doxylink{class_player_base_aa56d96c5b80fe3de32ee8ec9cec3df10}{draw()} wymuszająca własny wygląd w klasach pochodnych
\item Obsługa kolizji ze ścianami
\item Przekazywanie klawisza ataku przez event system
\end{DoxyItemize}

Klasa jest abstrakcyjna -\/ nie można stworzyć jej obiektu bezpośrednio. Należy użyć jednej z klas pochodnych\+: \doxylink{class_warrior}{Warrior}, \doxylink{class_mage}{Mage} lub \doxylink{class_archer}{Archer}.
