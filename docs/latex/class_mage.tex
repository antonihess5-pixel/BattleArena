\doxysubsection{Detailed Description}
Mag -\/ klasa postaci walczącej na dystans pociskami magicznymi. 

Dziedziczy po \doxylink{class_player_base}{Player\+Base} i nadpisuje metody \doxylink{class_mage_ab98ba259e9364c98495f008fa692a74f}{update()} oraz \doxylink{class_mage_adbe2cd3721d3c445d77c16fa0104e9bf}{draw()} aby zaimplementować własny system strzelania pociskami.

Mag nie używa ataku wręcz -\/ zamiast tego strzela fioletowymi kółkami z prędkością 400px/s. Posiada najniższe HP ale najwyższą prędkość ruchu.

Statystyki\+:
\begin{DoxyItemize}
\item HP\+: 80 (najniższe)
\item Prędkość\+: 250 px/s (najwyższa)
\item Obrażenia\+: 15 (najniższe)
\item Zasięg\+: daleki (pociski 400px/s, cooldown 0.\+3s) 
\end{DoxyItemize}
