Detailed Description

Reprezentuje pojedynczą ścianę na planszy.

Ściana leży na krawędzi między dwoma węzłami siatki i może być:

  • Pozioma: węzły mają takie samo Y, różne X
  • Pionowa: węzły mają takie samo X, różne Y

Ściany blokują ruch graczy i niszczą pociski przy kontakcie. Pozycja ściany w pikselach jest obliczana na podstawie współrzędnych węzłów, rozmiaru kratki i offsetu siatki.

Sprawdza czy ściana zajmuje podaną pozycję w siatce.

Sprawdzanie jest symetryczne: ściana A→B jest taka sama jak B→A. Używane aby zapobiec postawieniu dwóch ścian w tym samym miejscu.
