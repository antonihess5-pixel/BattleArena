Detailed Description

Apteczka pojawiająca się losowo na planszy.

Gracz który wejdzie na apteczkę odzyskuje określoną ilość HP. Apteczka znika po podniesieniu. Wizualnie reprezentowana jako zielony krzyżyk na planszy.
